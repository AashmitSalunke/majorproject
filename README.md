# 🏨 Hotel Transalvenya

A full-stack **Airbnb-inspired hotel booking platform** built using the **MERN Stack**, enabling users to discover, list, and manage properties with secure authentication, interactive maps, and an AI-powered chatbot for booking assistance.

---

## 🚀 Features

- 🔐 **JWT Authentication**
  - Secure user registration and login
  - Protected routes
  - Session management

- 👥 **Role-Based Access Control**
  - Separate permissions for users and property owners
  - Secure listing management

- 🏠 **Property Listings**
  - Create, edit, update, and delete listings
  - Upload property details and images
  - Property descriptions, pricing, and availability

- 🗺️ **Interactive Maps**
  - Integrated **Mapbox/Leaflet**
  - Property geolocation
  - Real-time map visualization

- 🤖 **AI Chatbot**
  - Booking assistance
  - Frequently asked questions
  - Customer support automation

- ⭐ **Reviews & Ratings**
  - Add and manage reviews
  - User feedback system

- 🔍 **Search & Filtering**
  - Search properties
  - Filter by location, price, and category

- 📱 **Responsive UI**
  - Mobile-friendly interface
  - Modern React.js frontend

# ⚙️ Installation

### Clone the repository

```bash
git clone https://github.com/your-username/Hotel-Transalvenya.git
```

### Navigate to the project

```bash
cd Hotel-Transalvenya
```

### Install dependencies

#### Backend

```bash
cd server
npm install
```

#### Frontend

```bash
cd ../client
npm install
```

---

# 🔑 Environment Variables

Create a `.env` file inside the **server** directory.

```env
PORT=5000

MONGO_URI=your_mongodb_connection_string

JWT_SECRET=your_secret_key

MAPBOX_TOKEN=your_mapbox_token

OPENAI_API_KEY=your_ai_api_key
```

---

# ▶️ Run the Project

### Start Backend

```bash
cd server
npm run dev
```

### Start Frontend

```bash
cd client
npm start
```
